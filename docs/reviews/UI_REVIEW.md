## 交互与键盘检查

1. 在 320 宽度英文首页按 Tab，首个焦点为 `Skip to content`，显示 `3px` 青色轮廓；按 Enter 后活动元素为 `main`。
2. 聚焦移动菜单按钮并按 Enter，`aria-expanded` 变为 `true`，8 项主导航可访问。按 Escape 后菜单关闭、`aria-expanded=false`，焦点回到菜单按钮。
3. 英文 Contact 点击 `中文` 后实际进入 `/zh/contact/`，没有返回首页；移动菜单进入中文论文页后自动收起。
4. 中文论文页检索 `Crystal` 得到 3 篇；叠加 `2021` 得到 2 篇；再叠加 `storage` 得到 0 篇并显示中文空结果提示；清空全部条件恢复 7 篇。
5. 论文页切至英文后输入无匹配关键词，显示 `0 publications shown` 与英文空结果说明，见 [截图](ui/en-publication-empty-320.png)。
6. 代码交叉检查：筛选器使用显式 `label`，结果数有 `aria-live="polite"`；移动菜单提供 `aria-controls`、`aria-expanded` 与 Escape 处理；无 JavaScript 时导航仍可见，论文仍可阅读；减少动态效果偏好已得到 CSS 支持。

## 非阻塞建议与边界

- 正式上线前，可在真实 iOS Safari / Android Chrome 和屏幕阅读器中追加验收；本次使用的是本地 Chromium 浏览器与键盘检查。
- 当前成员名单与招生细则的 TODO 是事实核验所需的明确占位，不属于模板示例数据。上线前应由课题组确认和补充；UI 审查不以共同作者推断成员身份。
- 页脚、来源说明和示意图图注字号偏小，但属于辅助信息且本次未出现遮挡或裁切。可根据课题组阅读偏好再适当加大，不列为必须修复缺陷。
- 本审查不替代另一位 Agent 的事实来源核验，也不宣称已经检查外部官方站点和 DOI 的实时可达性。
